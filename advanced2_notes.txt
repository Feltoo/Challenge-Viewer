When a code performs an invalid operation (eg. trying to cast a variable containing letters to 
integer), it will terminate the program with an error code. Errors commonly comes from user 
entering invalid input data. Instead of ending the program abruptly, you can handle the error in your 
code. Try-except allows you to do that.

Must I code using functions? 
You are learning coding to understand and write real ‑world applications. Writing code as 
functions is NOT OPTIONAL .  Real applications are complex, and functions are essential 
for debugging, teamwork, maintenance, readability, and reuse. Skipping them may work 
for small exercises, but it is unsustainable in professional practice. 
It is INCORRECT PRACTICE to write your entire program in one main block and only later 
try to rearrange it into functions.  The correct approach is to design your code structure 
with functions from the start and progressively build them up. This approach helps you 
break down programs, no matter how complex, and allows you to develop and test them 
progressively. 
The curriculum will begin with small functions. Over time, your main code will shrink and 
naturally evolve into a structured program built around functions.

FILE INPUT OUTPUT 
In order to save data permanently, you need to write them into ﬁles for subsequent retrieval. A ﬁle can be 
written in text format or binary format . A text format can be opened by any editor like note pad or word but a 
binary ﬁle requires interpretation to be readable. We will only be handling text format in this course. 
To open a ﬁle for reading and writing the following command is used: 
with open( filename  ,  mode  ) as myfile  :
eg. "myfile.txt" file variable 
Mode Description 
"r" Read only (default). File must already exist. 
"r+" Read+Write. File must already exist. 
"w" Write only. Overwrites if file exists, otherwise creates a new file for writing. 
"w+" Read+Write. Overwrites if file exists, otherwise creates a new file for writing. 
"a" Appending. If file does not exist, new file will be created. 
"a+" Append+Read. If file does not exist, new file will be created.

FILE INPUT OUTPUT 
Some commonly used commands for ﬁle operations are shown below. 
We will focus on readline() and write() for subsequent examples. 
Command Description 
read(n) Read at most n characters form the file. Reads till end of file if n is negative or None. 
readline(n) Read and return one line from the file. Reads in at most n bytes if specified. 
readlines(n) Read and return a list of lines from the file. Reads in at most n bytes/characters if specified. 
write(string) Write a string to the file. 
writelines(lines) Write a list of lines to the file. 
tell() Returns the current file position (in bytes). 
seek(position) Go to file position (in bytes).

You can shift the position of a ﬁle pointer manually. 
Use tell() to save the current pointer position into a variable. The value indicates the 
number of bytes (one character is one byte in ASCII code format) 
   position = f. tell() 
Use seek() to shift the ﬁle pointer to a position 
    f.seek( position )
Note that any invisible characters such as the newline character will also be considered 
as a character when reading, writing and seeking.

To start a turtle program, there are 4 main steps: 
1.Set up a canvas (the screen for drawing). Online IDE may have a default canvas 
without creating. But you will need to do this step in order to control the screen. 
2.Set up a turtle pen. It is the cursor on the screen that draws as it moves. You can 
have more than one pen with diﬀerent attributes (colour, line width, etc). 
3.Start drawing with turtle commands. 
The following slides will demonstrate with examples.

TURTLE 
In Turtle, you cannot ﬁll a shape that has already been drawn. You must indicate that you are going 
to perform ﬁlling before drawing the shapes. 
There are 4 steps for ﬁlling shapes with colours: 
1.Set outline and ﬁll colours (this overwrites existing pen colour) using .color() and .ﬁllcolor()
2.Enable ﬁll using begin_ﬁll() 
3.Draw all the shapes that you want to be ﬁlled with these colours. Whenever a closed shape is 
formed, it will be ﬁlled. 
4.Disable ﬁll when you are done using end_ﬁll() and all closed shapes will be ﬁlled.
