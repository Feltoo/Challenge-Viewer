VARIABLE NAME
The name of a variable must begin with either a letter or an underscore "_" . 
Followed by any letters, digits or underscores. No spaces are allowed.
Examples of valid names
name
num4
first_name
_length
_1stPlayer
_02
i
Examples of invalid names
first  name
<- space not allowed
1st_Player
<- first character must be letter or underscore
circle.radius
<- only letters, digits and underscore are allowed
Use meaningful names for variables. By convention, programmers use lower case for variables 
(although upper case is allowed) and words are separated with underscore.

CASTING
In order to perform certain operations, you need to cast them to the right data type. 
For example, you can only divide numbers and not string.
value = 9
value= str(value)
value = int(value)
value = float(value)
The variable named value is assigned an integer 
This changes it to a string '9'
This changes it to a float 9.0
To cast to float, value must contain only digits or with one 
decimal point (e.g. 9, 9.0, 9.123, etc) 
This changes it back to integer 9
To cast to integer, value must contain only digits

CASTING
Note that casting does not change the variable, it only takes the 
value and return the cast value. Below shows an example.
num = 9
print( num )
print( float(num) )
print( num )
num = float(num)
print( num )
The variable num is assigned an integer 9
As num remains as integer, it displays 9
This displays 9
float(num) converts the value and returns 9.0 but does not change the variable num
It displays the result 9.0
To change the variable type, you need to assign it back.
Now num is a float type with value 9.0

As it loops, i will count 5, 7, 9 (add 2 each count)

If you indicate only 1 value, it will be taken as the end with 
default start 0 and step 1. As it loops, i will count 0, 1, 2, 3, 4

About Python Round Method
Note about Python rounding:
In Python, the rounding method is a little diﬀerent in the way they handle numbers that are 
exactly halfway between two possible rounded values. 
In school, you could be taught the "round half up" method, where numbers that are exactly 
halfway will be rounded up. For examples, 1.5 rounds to 2 and 2.5 rounds to 3. 
Python uses Banker's rounding ("round half to even"), where such numbers will be rounded 
to the nearest even number instead. For example, both 1.5 and 2.5 will be rounded to 2. 
Banker's rounding are normally used in ﬁnancial and statistical sectors to improve accuracy. 
In this curriculum, you do not have to worry about the precision issue due to the diﬀerent 
rounding methods. The following slides will show you how to perform "round half up" for your 
interest.

import math
